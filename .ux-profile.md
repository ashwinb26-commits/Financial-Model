# UI and UX profile

Recorded so later work on this project stays consistent. Edit it when the
answers change.

## Aesthetic reference

Stripe. Refined typography, balanced depth, data tables that are easy to read,
high clarity. The subject is equity research, so the page should read like a
worksheet that shows its working, not like a marketing site.

## Accessibility target

WCAG 2.1 AA. Contrast at least 4.5:1 for normal text and 3:1 for large text and
borders. Hit targets at least 44 by 44 pixels.

## Microcopy voice

Utilitarian and minimal. Verb-first buttons in sentence case. Errors state what
happened and the next step, and never blame the reader.

## Colour

One accent hue carries every interactive element.

| Token | Value | Use |
| --- | --- | --- |
| canvas | #e9edf0 | Page background, roughly 60% of the viewport |
| surface | #ffffff | Panels and tables, roughly 30% |
| accent | #0f6b61 | Buttons, links, focus, chart series. 6.3:1 on white |
| ink | #15202e | Body text, 16.4:1 on white |
| ink-secondary | #4a5a6b | Supporting text, 7.1:1 |
| ink-muted | #64737f | Helper and meta text, 4.9:1 |
| warn | #8a5300 | Extraction in progress, warnings |
| neg | #9b2c2c | Illustrative data, deductions, decreases |

Status colours carry meaning only. They never decorate. Elevation is a 1px
border at 11% ink first, then a shadow at 0.05 alpha if it is needed at all.

## Type

IBM Plex Sans for the interface and prose. IBM Plex Mono for every figure, with
tabular numerals, so columns of numbers line up.

Weights are limited to 400, 500 and 600. Sizes are 12, 14, 16, 20, 25, 31 and
39 pixels. 12px is for footnotes, axis labels and helper text only. Table bodies
and form values use 14px or 16px. Headings use a line height of 1.2, body uses
1.55.

## Banned

- Glassmorphism and backdrop blur
- Multi-colour or rainbow gradients on buttons
- Cartoon illustrations in empty states
- Decorative pill wrappers around static metadata
- Tracked-out all-caps eyebrow labels above headings
- Meta strings joined with middle dots
- Arrows appended to button and link text
- Monospace used for decoration rather than for figures
- Font weights above 600

## Motion

Durations of 100, 150, 200 or 300ms. Ease-out on enter, ease-in on exit. Only
transform and opacity animate. Everything has a prefers-reduced-motion path
that is instant or opacity only.

## Icons

The project's own set in src/components/icons.tsx. 8 marks on a 16 pixel grid
at a 1.5 stroke. No icon library, no emoji. Icon-only buttons are square, at
least 44 by 44 pixels, and carry a real tooltip on hover and on keyboard focus
plus a separate accessible name. Where 2 icon buttons would use the same mark
for different actions, they get visible labels instead.

## Page patterns

- Public dashboard: Analytics and Reporting
- Sign-in: Form, auth variant, centred card with no app chrome
- Admin studio: Form, long edit, one route per section

## Dark mode

Not implemented. Financial research reads light, and a half-built dark theme is
worse than none. If it is added later, follow the colour-palette rule: edge
lighting and border contrast rather than outer glows.
